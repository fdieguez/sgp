================================================================================
GUÍA RÁPIDA DE RENOVACIÓN DE CERTIFICADOS SSL (HTTPS) EN PRODUCCIÓN
================================================================================

Este documento detalla el paso a paso exacto para renovar manualmente los 
certificados de seguridad SSL (HTTPS) de los sitios web cuando expiren o estén 
próximos a vencer.

--------------------------------------------------------------------------------
PASO 1: Conectarse al Servidor
--------------------------------------------------------------------------------
Abre una terminal o tu cliente SSH (como PuTTY o la terminal de Windows) y 
conéctate con las credenciales de administración:

  Comando: ssh root@149.50.128.168 -p 5287
  Contraseña: (Ingresar la clave de acceso de root)

--------------------------------------------------------------------------------
PASO 2: Detener los Contenedores Docker (Liberar Puerto 80)
--------------------------------------------------------------------------------
Nginx se ejecuta dentro de un contenedor Docker y tiene tomados los puertos 
80 y 443. Para que Certbot pueda verificar que eres dueño del dominio, debes 
detener temporalmente el servicio:

  cd /root/deploy/sgp/sgp/code
  docker compose down

--------------------------------------------------------------------------------
PASO 3: Ejecutar la Renovación de Certificados
--------------------------------------------------------------------------------
Ejecuta el comando de Certbot para renovar de forma automática todos los 
certificados configurados en el host:

  certbot renew --no-random-sleep-on-renew --force-renewal

Espera a que el proceso finalice. Deberías ver un mensaje de éxito como:
"Congratulations, all renewals succeeded" seguido de las rutas a los archivos .pem.

--------------------------------------------------------------------------------
PASO 4: Volver a Iniciar los Servicios
--------------------------------------------------------------------------------
Una vez finalizada la renovación con éxito, vuelve a encender los contenedores 
Docker. Nginx cargará automáticamente los nuevos certificados renovados del host:

  cd /root/deploy/sgp/sgp/code
  docker compose up -d

--------------------------------------------------------------------------------
PASO 5: Verificar el Estado del Sistema
--------------------------------------------------------------------------------
1. Comprueba que los contenedores estén corriendo de manera correcta:
   docker ps

2. Accede a los sitios desde tu navegador para confirmar que no se muestra 
   el aviso de "Sitio no seguro":
   - https://solicitudes.ultrasoft.website/
   - https://megabares.ultrasoft.website/

--------------------------------------------------------------------------------
MANTENIMIENTO ADICIONAL:
- Si deseas verificar cuántos días de validez le quedan a cada certificado antes 
  de iniciar el proceso, puedes ejecutar:
  certbot certificates
